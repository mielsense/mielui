# Mielui

Svelte components for building interfaces with a shared visual system. Use them as shipped, or copy the source and make them your own.

![Components](https://img.shields.io/badge/Components-77-ba7ca5) [![npm version](https://img.shields.io/npm/v/@mielui/svelte?color=ba7ca5)](https://www.npmjs.com/package/@mielui/svelte)

Mielui is independently maintained and originated from Sivir UI. Its component APIs, motion, theme system, CLI, and documentation have since developed separately. See [UPSTREAM.md](UPSTREAM.md) for the import history and retained credits.

Requires Svelte 5.56 or newer and Tailwind CSS v4. SvelteKit is optional.

## Documentation

Visit [ui.miel.my/docs/introduction](https://ui.miel.my/docs/introduction) for the documentation.

## Agent skill

Install the Mielui skill for component guidance, API references, and examples:

```sh
npx skills add mielsense/mielui --skill mielui
```
