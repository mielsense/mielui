# Sivir UI changelog archive

These entries document Sivir UI releases through the imported version, 0.3.3. They are retained as historical context for Mielui's source foundation, not as Mielui release notes or current API guidance.

Mielui versions independently, starting at 0.1.0. Read the [Mielui changelog](../../changelog/) for its releases and the [Mielui documentation](https://ui.miel.my/docs/introduction) for current usage.

The archived entries retain their historical wording. See [UPSTREAM.md](../../UPSTREAM.md) for the imported commit and attribution, and [LICENSE](../../LICENSE) for the retained MIT notices.
