- `Composer.Toolbar` renames and swaps its two looks. `variant` is now `'default' | 'inset'` and `chrome` is gone. The default joins the toolbar to the input on one surface. `variant="inset"` puts the input on its own inset surface with the toolbar in the frame under it, like an inset Card. To keep the look you had, add `variant="inset"` where you set nothing or `chrome`, and remove it where you set `inset`.
- `DataTable.ColumnHeader` sorts on click instead of opening a menu. Each click moves to the next state: ascending, descending, then unsorted. Shift-click adds the column to a multi-column sort. Three new optional labels cover its tooltips: `sortAscending`, `sortDescending` and `clearSorting`.
- Data Table's inset variant frames only the table and its footer. `DataTable.Toolbar` now floats above the frame instead of sitting inside it.
- `DropdownMenu.Item`, `ContextMenu.Item`, `ContextMenu.CheckboxItem`, `Select.Item` and `Combobox.Item` no longer accept `href`. These rows always rendered a button and ignored it. Navigate from `callback` instead.
- Surfaces are solid by default. Menus, dialogs, popovers, toasts and the Composer were frosted glass unless a theme said otherwise. To get glass back, set `--mielui-surface: glass` on `:root`, turn it on in Theme Studio, or pass `surface="glass"` to one component. Built-in presets that do not set a surface are solid now too.
- The default theme's font is Manrope instead of Inter. `ui.css` now imports `@fontsource/manrope`, and the package no longer depends on `@fontsource/inter`. To keep Inter, install `@fontsource/inter`, import its CSS, and set `--font-sans: 'Inter', sans-serif`.
